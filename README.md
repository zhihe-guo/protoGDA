## What this repository contains

- Data preprocessing and the pharmacophore Gaussian Mixture Model (GMM) pre-computation pipeline: `scripts/precompute_conformers.py`, `scripts/precompute_pharmacophores.py`, `scripts/precompute_chemberta.py`
- Model implementation: `src/models/`
- Training and evaluation for four splits (unblinded, cell-line-blind, drug-blind, scaffold-blind): `scripts/train.py`, `scripts/cv_runner.py`, `scripts/eval.py`
- Formal configurations: `config/cellquery_interpolation.yaml`, `config/cellquery_cell_cold.yaml`, `config/cellquery_drug_cold.yaml`, `config/cellquery_scaffold_cold.yaml`
- Baseline reimplementations used for comparison: `baselines/candela/`, `baselines/mgataf/`, `baselines/graphdrp/`
- Attention-weight export: `scripts/export_attention.py`

`config/default.yaml` is a development template. `config/exp_*.yaml` and `config/cv_abl_*.yaml` are ablation or development settings; they are not additional reported protocols.

This repository does not provide a Zenodo archive or a one-command workflow that regenerates every table and figure. Feature caches under `data/` are created locally and are not redistributed.

## Installation

```bash
pip install -e ".[linux-data,dev]"
```

On Windows, install the base package and then `requirements-data-windows.txt`. GDSC2 is loaded through Therapeutics Data Commons with `DrugRes(name="GDSC2")` and PyTDC 1.1.15: https://tdcommons.ai/multi_pred_tasks/drugres/

Missing conformer, pharmacophore, or ChemBERTa caches are generated by the preprocessing scripts when training starts. The CANDELA and MGATAF baselines expect a locally prepared `data/gdsc2.pkl`.

## Formal training protocol

Reported cross-validation uses seed 42, six folds, and selects each fold checkpoint by validation Pearson correlation. Drug-blind and scaffold-blind formal runs use 60 epochs with early stopping disabled.

```bash
python scripts/cv_runner.py --model cellquery --k 6 --split_by drug_cold \
    --config config/cellquery_drug_cold.yaml --epochs 60 --patience 999 \
    --checkpoint-metric pearson_r --out checkpoints/protoGDA_drug_cold
```

Replace `--split_by` and `--config` with `interpolation`, `cell_cold`, or `scaffold_cold` and the matching `config/cellquery_*.yaml`. Baseline runs use `--model candela` or `--model mgataf` with the corresponding file under `baselines/`.

GDSC1 zero-shot evaluation is `scripts/external_validate_gdsc1.py`. It requires a locally prepared `data/gdsc1.pkl` and saved drug-blind checkpoints.

## Supplementary checkpoints

`pretrained/` contains checkpoints and `cv_results.json` summaries from the formal runs already completed. The fold-mean Pearson values in those summaries correspond to the cross-validation means reported for those runs. These files are supplementary: the manuscript does not treat them as an archived release, and they do not by themselves regenerate the figures.

## Attention export

```bash
python scripts/export_attention.py \
    --config config/cellquery_drug_cold.yaml \
    --checkpoint pretrained/protoGDA_drug_cold/fold_1/best.pt \
    --out results/attention_example
```

The script evaluates one batch with `return_attention=True` and writes per-layer probe-to-atom weights plus a heatmap. It does not require retraining.

## Terminology

The four evaluation scenarios are unblinded, cell-line-blind, drug-blind, and scaffold-blind. Internal configuration names remain `interpolation`, `cell_cold`, `drug_cold`, and `scaffold_cold`. The drug-tower attention mechanism is invariant-based graph attention inside EGNN, not a separate EQGAT module.

# 药效团模态优化分析（2026-08-07）

> 本分析基于 25-epoch 对照实验（drug_cold + interpolation 各 7 组配置），
> 全部结果如实记录于 `results.md`，无任何筛选或后处理。

## 一、现有实验的诚实结论

### 1.1 3D 通道增强未能兑现

| 配置（drug_cold） | Pearson | 相对基线 |
|---|---|---|
| EGNN+pharm（saturated 基线） | 0.642 | — |
| + gaussian RBF | 0.618 | -0.024 |
| + equiv feats | 0.583 | -0.059 |
| + gaussian RBF + equiv feats | 0.592 | -0.050 |
| + 自注意力 | 0.564 | -0.078 |

| 配置（interpolation） | RMSE | 相对基线 |
|---|---|---|
| EGNN+pharm（saturated 基线） | 1.008 | — |
| + gaussian RBF | 1.152 | +0.144 |
| + equiv feats | 1.204 | +0.196 |
| + gaussian RBF + equiv feats | 1.185 | +0.177 |
| + 自注意力 | 1.150 | +0.142 |

**解读**：所有"增强 3D 通道"的尝试（更精细的距离编码、演化坐标注入、自注意力）都**降低了**性能。
自注意力（等变性已验证正确）仍无增益，说明瓶颈不在"如何路由 3D 信息"，而在"单构象 3D 距离
本身信息量不足"——模型从键类型（edge_attr）、Morgan、ChemBERTa、药效团协方差特征中已获得足够的药物表示。

### 1.2 药效团模态的定位

- 对 **EGNN**：小幅正向（0.625 → 0.642，+0.017 Pearson）——真实但微弱。
- 对 **GAT**：负向（0.655 → 0.458，-0.197 Pearson）——显著损害。
- 对 **interpolation**：无帮助（1.008 vs GAT 0.991）。

**解读**：药效团特征需要配合"能用它的架构"。EGNN 因为自带 3D 通道，对药效团的
逐原子标量特征有轻微协同；GAT 的注意力路由会忽略它，反而因节点维度增加（+18）而受损。
这与"协方差特征 + 注意力路由 = 最优组合"的假设**不符**。

### 1.3 药冷评估的固有噪声

drug_cold 验证集仅 13 个药物（test 29 药），val_rmse 波动极大，导致：
- 早停全部在 epoch 5-6 触发（interpolation 在 epoch 22-25）；
- "best checkpoint"实际是验证集噪声低谷，而非泛化最优；
- Test 表现"好于"Valid 是**统计稳定性差异**，不是模型真实优势。

## 二、可落地的优化方向（按优先级）

### 方向 A：修复 drug_cold 的评估/早停机制（高优先级，成本低）

**问题**：13 药的验证集无法可靠选点，早停失真。

**方案**：
1. drug_cold 下用 **Pearson 而非 RMSE** 做早停指标——Pearson 对每药物
   IC50 均值偏移不敏感，能更好反映排序能力；
2. 或 drug_cold 下**增大 valid 药物数**（当前 13 → 建议 ≥20，调整 split 比例
   0.7/0.1/0.2 → 0.65/0.15/0.2）；
3. 或在验证集上**按药物聚合再算 RMSE**（先每药物内去均值，再算全局），
   消除"药物碱线"主导 RMSE 的问题。

**预期收益**：选点更可靠，Test 与 Valid 的关系更可信，早停不再提前 5 epoch 停掉。

### 方向 B：EGNN 自注意力（已实现并验证，结论为负面）

**现状**：`egnn_use_attention` 已在 EGNNLayer 实现，等变性验证通过（h/pos 旋转差 ~1e-7）。
**验证结果**（25 epoch 同口径）：
- drug_cold：Pearson 0.564（基线 0.642）；
- interpolation：RMSE 1.150（基线 1.008）。
**结论**：给 EGNN 补上注意力并未带来增益。结合 gaussian RBF / equiv feats 也全部为负，
可以判定 **"单构象 3D 距离信息本身边际" 而非 "路由方式不当"**。此方向不再优先推进。

### 方向 C：让药效团特征"被感知"（根因已定位）

**诊断结论（2026-08-07 深夜，见 results.md）**：
- 旧假设（"与指纹相关导致冗余"）**被推翻**。决定性对照：
  - GAT+零pharm（0.450）≈ GAT+真pharm（0.458）——伤害**不是 pharm 内容**；
  - GAT+随机噪声（0.634）≈ GAT 无 pharm（0.655）——纯随机不伤害；
  - **GINE+pharm（0.684）> GINE 无 pharm（0.616）> GAT 无 pharm（0.655）**。
- 真实机制：**药效团是重原子的空间柔性摘要，只有在有"3D/键合语境"（edge_attr/pos/RBF）的 GNN 中才能被正确消费**。
  - EGNN/GINE 有 edge_attr 语境 → pharm 正贡献；
  - GAT 无 pos、无 edge_attr → pharm 的稀疏非零模式（非零原子 66.7% 是芳香）被注意力误当"原子身份"重复编码，且与 IC50 弱相关（r=-0.25）→ 误导注意力。

**方案（按优先级）**：
1. **给 GAT 启用 edge_attr 语境**（`edge_proj` 对 gat 开放，GATv2Conv 原生支持 edge_attr）——让药效团从"负贡献"转为"正贡献"（GINE 已验证此机制，0.684 > 0.655）；
2. 或直接使用 **GINE + 药效团**作为标准配置（已实测 drug_cold Pearson 0.684，为当前所有配置最高）；
3. 药效团特征不进 atom_proj、改从 GNN 输出后单独 gate 注入——作为备选精细方案。

### 方向 F（新增）：EGNN 的整体劣势根因 = 含氢坐标噪声

诊断证据：
- H 原子占图节点 44.1%、H 相关边占 41.9%——EGNN 近半 RBF 消息涉及 H；
- H 坐标构象间波动是重原子的 3.23 倍（柔性末端甲基达 1.3Å）；
- 即 EGNN 约 42% 的消息预算用于编码"对 IC50 无信息且高噪声"的氢位置。

改进方向：**重原子图（去 H）+ RBF**，或对 H 边降权；可预期显著提升 EGNN 的 drug_cold 表现。

### 方向 D：多构象的真正价值（学术对比用途）

用户明确：多构象聚合**不作主干**，仅作对比实验。建议未来在消融中加入：
- "单构象 + 药效团" vs "多构象平均 + 药效团"——用于论证 GMM/协方差
  替代多构象是**信息无损甚至更优**的。

### 方向 E：数据/特征层面（非架构）

GDSC2 只有 137 药，drug_cold 的 29 个测试药物本身就是极大挑战。
若目标是"药物冷启动"，可考虑：
1. 用更大的数据集（如 GDSC1 合并，或 CCLE/CTRP 的 500+ 药）重训，看冷启动是否更可靠；
2. ChemBERTa/Morgan 是强先验，药冷下模型靠它们就能输出先验均值——应评估
   在 drug_cold 下**只用原子特征 + 药效团**（去掉指纹）能否倒逼模型学习分子结构
   到响应的泛化映射。

## 三、明确的"不造假"承诺

- 所有数据来自真实运行，记录于 `results.md`；
- 未对失败的实验做任何筛选/事后挑选；
- "方向 A"（修复评估）是**实验设计缺陷修复**，不是为了让指标变好而调整；

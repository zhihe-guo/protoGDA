
# CellQuery: 思路与架构

## 摘要

**CellQuery** 是一个用于药物-细胞系相互作用预测（IC50/毒性）的深度学习模型。其核心思想是：**将细胞系的多组学特征作为一组可学习的"探针"，在分子图每一层演化之后对其进行单向交叉注意力析取，析取结果通过残差连接累加到一个独立的累积记忆对象中。最终预测仅使用该累积对象，与原始分子图和细胞系特征完全解耦。**

## 1. 设计动机

### 1.1 现有方法的不足

**图池化问题**：传统图神经网络在分子性质预测中，通常将图的最后一层节点特征做全局平均池化或总和池化，再送入 MLP。这种操作粗暴地抹杀了不同原子间的差异，相当于"扫一眼就下结论"。

**虚拟节点过度平滑**：一些工作在图中引入虚拟节点（Virtual Node），但采用双向同步更新会使其在早期就被全局连接特性所冲淡，引发 GNN 中经典的过度平滑问题。

**双塔模型缺乏空间交互**：在药物-细胞系多模态预测中，主流的 Twin-Tower 双塔模型是"药物出一个向量，细胞系出一个向量，最后做点积或拼接"。这种方式完全忽略了药物分子内部的拓扑结构（哪个基团对哪个通路敏感），也抹杀了空间交互。

**靶点引入的困境**：很多药物的毒性并非由已知靶点引起，而是由于脱靶效应、代谢产物或非特异性结合。盲目引入靶点特征，反而会带来数据噪声和过拟合。

### 1.2 核心启发

本方法借鉴了以下直觉：

- **药效团识别**：药物毒性往往由特定的子结构（环、活性基团）引起。一个理想的模型应该能逐层"关注"到这些子结构。
- **多尺度融合**：浅层 GNN 捕捉局部官能团，深层 GNN 捕捉全局拓扑和电荷分布。对每一层都做独立的注意力查询，就等价于同时关注从局部到全局的所有尺度。
- **探针隐喻**：细胞系的不同生物学通路（免疫、代谢、DNA 修复等）对药物的不同子结构有不同的敏感度。让细胞系成为"探针"，每个探针关注不同的子结构。

## 2. 架构总览

```
Cell_Features (B × 17737)
  │
  ▼
MLP Projector
  │
  ▼
Q (B × M × D)  ────────────────────────────────────────────────┐
                                                                │ (每层复用，不变化)
Drug_SMILES ──► Mol_Graph (V × D) ──► GNN₀ ──► Graph₁ ──► ... ──► Graph_L
                    │                   │            │
                    ▼                   ▼            ▼
               CrossAttn₀          CrossAttn₁    CrossAttn_L
                    │                   │            │
                    ▼                   ▼            ▼
        M_accum ──► + ──► M_accum ──► + ──► ... ──► M_accum ──► Flatten ──► MLP ──► ŷ (IC50)
```

整个模型由三类核心对象构成：

| 对象 | 符号 | 维度 | 含义 |
|------|------|------|------|
| 细胞系探针矩阵 | `Q` | `(B, M, D)` | 从细胞系组学特征投影而来的 M 个"通路探针"，全程不变 |
| 药物图节点 | `H_graph^{(l)}` | `(N, D)` | 每一层 GNN 演化后的分子图节点特征 |
| 累积记忆对象 | `M_accum` | `(B, M, D)` | 收集并叠加各层析取结果，初始化自 Q，最终展平送入读出层 |

**关键约束**：
- `Q` 单向查询图节点，**绝不回写**，图演化完全独立
- `M_accum` 接收每一层的析取结果，最终只有它进入预测
- 交叉注意力输出始终为 `(M, D)`，**与药物原子数 V 无关**——这是架构最优雅的特性

## 3. 逐层计算详解

### 3.1 细胞系特征投影（CellQueryProjector）

```
细胞系基因表达 (B × 17737)
    → MLP (17737 → 512 → M × D)
    → Q (B × M × D)
```

- 17,737 维的 RMA 归一化基因表达，先经两层 MLP 降维到 `(M, 256)`
- M 个探针各有一个可学习的偏置向量 `probe_bias[M, D]`，使得各探针差异化，可最终对不同的生物学通路产生不同的关注模式
- 输出 Q 在后续所有层中**固定不变**——探针本身不学习，让它在同一尺度下去扫描不同深度的图特征

### 3.2 单向交叉注意力（GraphCrossAttention）

每一层中，Q 对当前图节点做**单向**多头交叉注意力（单向：Q 只读图，不写图）：

1. 线性投影：

   $$Q \leftarrow \text{Linear}_Q(Q), \quad K \leftarrow \text{Linear}_K(H_\text{graph}), \quad V \leftarrow \text{Linear}_V(H_\text{graph})$$

2. 多头的按样本计算（每个分子图的原子数不同，因此逐样本计算）：

   $$\text{Attention}(Q_i, K_i, V_i) = \text{softmax}\left( \frac{Q_i K_i^T}{\sqrt{d_h}} \right) V_i$$

3. 维度魔术：

   $$Q_i \in (M, D),\ K_i \in (V_i, D) \ \Rightarrow\ \text{Attention Map} \in (M, V_i) \ \Rightarrow\ \text{Output} \in (M, D)$$

   注意 `V_i` 出现在结果中 → **被消掉了**。输出维度只由探针数 M 和隐藏维度 D 决定，与分子大小无关。

4. 输出经 LayerNorm 和残差连接后传给累积记忆对象。

### 3.3 图演化（GraphEvolver）

图的节点特征独立进入 GNN 层，支持三种可切换骨干网络：

| GNN 类型 | 说明 |
|----------|------|
| **GATv2**（默认） | 动态注意力图卷积，每个原子自适应地决定邻居的重要性 |
| **GCN** | 经典图卷积 |
| **GINE** | 同时利用边特征（化学键类型）的图同构网络 |

每层 GNN 后经 LayerNorm、GELU 激活、Dropout 和残差连接：

$$H_\text{graph}^{(l+1)} = H_\text{graph}^{(l)} + \text{Dropout}\big( \text{GELU}\big( \text{LayerNorm}\big( \text{GNN}(H_\text{graph}^{(l)}, E) \big) \big) \big)$$

### 3.4 累积记忆更新（MemoryAccumulator）

每一层析取出的特征 $E^{(l)}$ 叠加到累积记忆中。支持两种模式：

**Residual 模式（纯加法，默认）**：

$$M_{accum}^{(l)} = M_{accum}^{(l-1)} + \text{LayerNorm}(E^{(l)})$$

**GRU 模式（门控更新）**：

$$M_{accum}^{(l)} = \text{GRUCell}(E^{(l)}, M_{accum}^{(l-1)})$$

GRU 模式更稳定（防止深层叠加时数值发散），但参数量略大。

### 3.5 读出层（Readout MLP）

训练结束后，只有 $M_{accum}$ 参与预测。原始分子图和初始细胞特征已经完成了使命：

$$M_{accum}^{(L)} \in (B, M, D) \xrightarrow{\text{Flatten}} (B, M \times D)$$

$$(B, 4096) \xrightarrow{\text{MLP: [512, 256]}} (B, 1) \rightarrow \hat{y}_\text{IC50}$$

## 4. 张量流动总结

以下以 `batch_size=64, M=16, D=256` 为例，追踪一个分子有 V=18 个原子的样本：

| 步骤 | 张量 | 形状 |
|------|------|------|
| 细胞系输入 | RNA-seq | `(64, 17737)` |
| 投影 | Q | `(64, 16, 256)` |
| 第 0 层 CrossAttn | Attn Map → E⁰ | `(16, 18)` → `(64, 16, 256)` |
| 第 0 层 M_accum | Q + E⁰ | `(64, 16, 256)` |
| 第 0 层 GNN | H → H' | `(18, 256)` → `(18, 256)` |
| ... | ... | ... |
| 第 L 层 CrossAttn | E^(L) | `(64, 16, 256)` |
| 第 L 层 M_accum | 最终状态 | `(64, 16, 256)` |
| Readout | Flatten → MLP | `(64, 4096)` → `(64, 1)` |

## 5. 可解释性

多头注意力的求权重矩阵天然适合可视化：

- **按探针**：M 个探针中，哪些更关注原子级别的局部官能团（浅层注意高），哪些更关注分子整体构象（深层注意高）？
- **按层**：同一个探针在第 0 层和第 4 层对不同原子的关注分布有何差异？——这揭示了分子特征在 GNN 演化过程中逐渐从局部到全局的信息聚合。
- **实验对照**：对于同一种药物，肝细胞系和肺癌细胞系对其不同原子的关注模式有何区别？——这揭示了细胞特异性药效团的可能。

注意力权重在 forward 中保存为 `attention_weights`，可在 [`notebooks/exploration.ipynb`](../notebooks/exploration.ipynb) 中可视化。

## 6. 工程实现

### 6.1 数据

使用 [Therapeutics Data Commons (TDC)](https://tdcommons.ai/) 的 GDSC2 数据集：

| 项目 | 数值 |
|------|------|
| 配对样本 | 92,703 |
| 细胞系数量 | 805 |
| 药物数量 | 137 |
| 细胞系特征 | 17,737 维（RMA 归一化基因表达） |
| 分子编码 | SMILES → RDKit → 144 维原子特征 + 6 维键特征 |
| 标签 | 对数 IC50（Ln IC50） |

### 6.2 代码组织

```
├── src/data/         # 数据加载、SMILES→图转换、归一化
├── src/models/       # cellquery.py (投影), layers.py (注意力/演化/累积), model.py (顶层)
├── src/training/     # 训练循环、早停、检查点
├── src/eval/         # RMSE / MAE / R² / Pearson / Spearman
├── scripts/          # train.py, eval.py
└── notebooks/        # 数据探索与注意力可视化
```

### 6.3 依赖

- **PyTorch + PyTorch Geometric**：图神经网络和 Torch 注意力计算
- **RDKit**：SMILES → 分子图（原子/化学键特征编码）
- **TDC**：自动下载和对齐 GDSC2 的 SMILES、基因表达和 IC50 标签
- **OmegaConf**：YAML 配置管理

跨平台安装指引见 [`README.md`](../README.md#setup)。

## 7. 与相关工作比较

| 模型 | 细胞-药物交互 | 多尺度 | 图独立性 | 可解释性 |
|------|:---:|:---:|:---:|:---:|
| Twin-Tower MLP | 全连接点积 | 否 | — | 低 |
| Graph + Pooling + MLP | 仅药物 | 否 | — | 中（原子归因） |
| **CellQuery** (本工作) | 交叉注意力逐层扫描 | 是（每层独立析取） | 是（图演化不受 Q 干扰） | 高（逐层逐探针注意力权重） |

## 8. 潜在改进方向

- **3D 构象扩展**：在 GNN 中引入原子的 3D 坐标作为边特征（间距、键角），使模型能感知药物分子的空间构象
- **多组学融合**：除基因表达外，引入突变谱、拷贝数变异作为额外的细胞系特征通道
- **预训练**：在 ChEMBL 或 ZINC 等大规模分子库上预训练 GNN 骨干，再在 GDSC2 上微调
- **生成式扩展**：在注意力权重引导下，尝试对药物分子进行对抗性扰动，生成"逃避免疫系统"的分子候选
